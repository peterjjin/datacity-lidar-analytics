Use Microsoft’s installer path, not the Ubuntu marketing page.

The current official way is:

wsl --install -d Ubuntu-22.04
Run that in an elevated PowerShell window, then reboot if prompted. WSL itself is part of Windows; you generally do not “download WSL” separately from Ubuntu’s site. Microsoft’s install guide is here: https://learn.microsoft.com/en-us/windows/wsl/install

The Ubuntu page you linked is fine as background and for Ubuntu-on-WSL details, but it is not the primary install path for WSL itself: https://ubuntu.com/desktop/wsl

If wsl --install stalls, Microsoft also documents:

wsl --install --web-download -d Ubuntu-22.04
Source: Microsoft Learn WSL install page, last updated August 6, 2025, and Ubuntu’s WSL page.
